# NLSY97

Один источник, три представления. В анализе используются 7 423 участника волны 2011 года; исходные выгрузки содержат всех 8 984 человек.

- `nlsy97/nlsy97_2011_selected_raw.csv` — 40 исходных столбцов волны 2011, включая заработок за 2010 год.
- `nlsy97/income_waves_raw.csv.gz` — повторные опросы 2004–2023, 14 волн. Годы заработка: 2003–2010, 2012, 2014, 2016, 2018, 2020, 2022.
- `nlsy97/employment_weeks_raw.csv.gz` — 228 недель, по одной на каждый месяц 2004–2022: неделя, содержащая 15-е число.
- `nlsy97/monthly_calendar.csv` — соответствие месяца, официальной недели и исходного столбца.
- `variables.json`, `panel_variables.json` и файлы `*codebook*.txt` в `nlsy97/` — словари выбранных переменных.
- [Источники и контрольные суммы](nlsy97/sources.json).

Все преобразования выполняются в ноутбуке. Отрицательные коды сохранены в исходниках. Файлы `.gz` читает `pandas.read_csv` без ручной распаковки.

Ряд занятости — доля работающих среди выбранных участников с известным гражданским статусом. Коды работодателей ≥ 9701 означают работу; 2, 4, 5 — отсутствие работы. Неизвестные/неоднозначные статусы (0, 1, 3), армия (6) и отрицательные коды исключены. Это не официальный показатель по населению США. Заработки номинальные, без поправки на инфляцию; верхний хвост обработан поставщиком (topcoding).
